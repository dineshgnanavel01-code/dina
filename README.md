# Flex Living — House Renting Website

A responsive house-rental website built with React, Vite, Tailwind CSS, JavaScript, Lucide icons, and React Router.

## Features

- Sticky responsive navigation with mobile menu
- Hero search with location, property type, bedrooms, and date fields
- Reusable property cards and featured listings
- Listings page with location, type, price, bedrooms, and amenities filters
- Favorite properties stored in localStorage
- Property details page with image gallery, amenities, availability, and booking CTA
- About, Contact, Login, and Sign Up pages
- Fully responsive from 320px mobile to 1440px+ desktop
- Clean reusable component and data structure

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Netlify

Build command: `npm run build`

Publish directory: `dist`

For React Router direct links on Netlify, the included `public/_redirects` file rewrites routes to `index.html`.
